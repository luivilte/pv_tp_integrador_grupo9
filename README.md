Descripción del proyecto:

Este proyecto consiste en el desarrollo de una aplicación web de catálogo de productos, realizada con React y tecnologías complementarias modernas.
El sistema simula un mini e-commerce, permitiendo a los usuarios visualizar productos, marcarlos como favoritos, y realizar operaciones de creación, edición y visualización detallada. Las tecnologias utilizadas en el proyecto fueron las siguientes:

React + Vite para la estructura y rendimiento moderno

Redux Toolkit para el manejo de estado global

React Router DOM para navegación entre páginas

Material UI (MUI) para componentes visuales profesionales

Fake Store API como fuente externa de productos

LocalStorage para persistencia de sesión y usuarios.
